### 1. 项目初始化

使用 Vite 初始化 Vue3 + TypeScript 项目：

```bash
npm create vite@latest my-project --template vue-ts

cd my-project

npm install
```

### 2. 安装所需依赖

在项目中安装以下依赖：

```bash
# 安装路由组件
npm install vue-router@4

# 安装网络请求组件
npm install axios

# 安装UI库
npm install ant-design-vue@4.x --save

# 安装状态管理库pinia 
npm install pinia

#  Vite 构建时需要
npm install --save @types/node

# Ant Design 的样式系统兼容
npm install sass -D
```

- **vue-router** 用于页面路由管理
- **axios** 用于请求后台 API
- **ant-design-vue** 用于 UI 组件库



### 3. 配置 Vite

Vite 默认支持 TypeScript，无需额外配置。可以在 `vite.config.ts` 中对别名进行配置，便于导入：

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': '/src'
    }
  }
})
```

### 4. 配置 Vue Router

在 `src/router/index.ts` 中配置路由：

```typescript
import { createRouter, createWebHistory, RouteRecordRaw } from 'vue-router'
import Home from '@/views/Home.vue'

const routes: RouteRecordRaw[] = [
  {
    path: '/',
    name: 'Home',
    component: Home
  },
  {
    path: '/about',
    name: 'About',
    component: () => import('@/views/About.vue')
  }
]

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes
})

export default router
```

### 5. 配置 Axios

在 `src/utils/axios.ts` 中创建一个 Axios 实例：

```
typescript复制编辑import axios from 'axios'

const api = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器
api.interceptors.request.use(config => {
  // 处理请求前的操作，如添加认证token等
  return config
})

// 响应拦截器
api.interceptors.response.use(response => {
  return response.data
}, error => {
  return Promise.reject(error)
})

export default api
```

### 6. 使用 Ant Design Vue

在 `src/main.ts` 中引入 Ant Design Vue 组件库：

```
typescript复制编辑import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import Antd from 'ant-design-vue'
import 'ant-design-vue/dist/antd.css'

const app = createApp(App)

app.use(router)
app.use(Antd)

app.mount('#app')
```

### 7. 创建页面和组件

在 `src/views` 目录下创建 `Home.vue` 和 `About.vue` 页面。例如，在 `Home.vue` 中使用 Ant Design Vue 组件：

```
vue复制编辑<template>
  <a-layout>
    <a-layout-header>
      <div class="logo" />
    </a-layout-header>
    <a-layout-content>
      <a-button type="primary" @click="handleClick">Primary Button</a-button>
    </a-layout-content>
  </a-layout>
</template>

<script lang="ts">
import { defineComponent } from 'vue'

export default defineComponent({
  name: 'Home',
  methods: {
    handleClick() {
      this.$message.success('Button clicked!')
    }
  }
})
</script>

<style scoped>
.logo {
  color: #fff;
  font-size: 20px;
}
</style>
```

### 8. 项目结构建议

```
bash复制编辑src/
  ├── assets/          # 静态资源
  ├── components/      # 公共组件
  ├── layout/          # 布局组件
  ├── router/          # 路由配置
  ├── store/           # Vuex 状态管理（如果需要）
  ├── utils/           # 工具函数（如 axios 请求封装）
  ├── views/           # 页面组件
  └── App.vue          # 根组件
```

### 9. 其他配置

- **状态管理**：可以使用 Vuex 或者 Pinia 来管理全局状态，推荐使用 Pinia，因为它是 Vue 3 官方推荐的状态管理工具。
- **代码分割**：可以使用动态 import 来实现代码分割，例如路由懒加载。
- **UI 主题**：可以使用 Ant Design Vue 提供的主题定制功能来修改默认样式。
