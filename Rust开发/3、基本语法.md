### 数据类型

Rust 语言中有四种标量数据类型：

- 整型
  - 有符号整型，英文 `signed`，既可以存储正数，也可以存储负数。
  - 无符号整型，因为 `unsigned`，只能存储正数。
- 浮点型
  - `f32` 又称为 **单精度浮点型**。
  - `f64` 又称为 **双精度浮点型**，它是 Rust 默认的浮点类型.
- 布尔类型
- 字符类型
  - **字符(char)** ，就是字符串的基本组成部分，也就是单个字符或字。
  - **Rust 使用 UTF-8 作为底层的编码** ，而不是常见的使用 ASCII 作为底层编码。
  - Rust 中的 **字符数据类型** 包含了 **数字**、**字母**、**Unicode** 和 **其它特殊字符**。



```rust
fn main(){
    let str = "字符串类型";  // string 字符串类型
    let number = 999.99;       // float 类型
    let checked = true;   // boolean 类型

    println!("str is:{}", str); //输出 str is:字符串类型
    println!("number is:{}", number);//输出 number is:999
    println!("checked is :{}", checked);//输出 checked is :true
}
```



上面的代码中，我们并没有为每一个变量指定它们的数据类型。Rust 编译器会自动从 **等号 =** 右边的值中推断出该变量的类型。例如 Rust 会自动将 **双引号** 阔起来的数据推断为 **字符串**，把没有小数点的数字自动推断为 **整型**。把 `true` 或 `false` 值推断为 **布尔类型**。



当数字很大的时候，Rust 可以用 **(_下划线) ** ，来让数字变得可读性更好。

```rust
let price1 =1_000_000;
println!("price1 {}", price1); //输出 price1 1000000

let price2 =1_000_000.666_123;
println!("price2 {}", price2);//输出 price2 1000000.666123
```





### 变量



**变量声明**： Rust 语言使用 `let` 关键字来声明和定义一个变量。

```rust
let 变量名 = 值;           // 不指定变量类型
let 变量名:数据类型 = 值;   // 指定变量类型


let mut 变量名 = 值;
let mut 变量名:数据类型 = 值;
```



#### 命名规范

1. 可以包含 **字母**、**数字** 和 **下划线** 。
2. 变量名必须以 **字母** 或 **下划线** 开头。不能以 **数字** 开头。
3. 变量名是 **区分大小** 写的。也就是大写的 Study 和小写的 study 是两个不同的变量。



#### 不可变变量

Rust 语言中使用 `let` 声明的变量，在第一次赋值之后，是不可变更不可重新赋值的，变成了 **只读** 状态。

默认情况下，Rust 语言中的变量是不可变的。

```rust
let price = 188;
price=288;
print!("{}",price);

编译器报错提示：Cannot assign twice to immutable variable [E0384]
```



#### 可变变量

Rust 语言提供了 `mut` 关键字表示 **可变的**。 在变量名的前面加上 `mut` 关键字告诉编译器这个变量是可以重新赋值的。

```rust
let mut price = 188;
price=288;
print!("{}",price); //输出 288
```



### 常量

**常量** 就是那些值不能被改变的变量。定义后，再也没有任何方法可以改变常量的值。

- const：不可改变的值（通常使用这种）。
- static：具有 ‘static 生命周期的，可以是可变的变量（须使用 static mut 关键字）。



>有个特例就是 “string” 字面量。
>
>它可以不经改动就被赋给一个 static 变量，因为它 的类型标记：&’static str 就包含了所要求的生命周期 ‘static。
>
>其他的引用类型都 必须特地声明，使之拥有’static 生命周期。





#### 常量定义

```
const 常量名称:数据类型=值;
```

1. 使用 const 关键字定义常量。
2. 定义常量时必须指定数据类型。
3. 常量名称的命名规则和之前变量的命名规则一样，但常量名称一般都是 **大写字母**。

```rust
// 全局作用域常量
const MAX_CONNECTIONS: usize = 1000;
const TIMEOUT_SECONDS: u64 = 30;
const DEFAULT_PORT: u16 = 8080;

fn main() {
    // 局部作用域常量
    const LOCAL_CONST: &str = "局部常量";
    
    println!("最大连接数: {}", MAX_CONNECTIONS);
    println!("超时时间: {}秒", TIMEOUT_SECONDS);
    println!("默认端口: {}", DEFAULT_PORT);
    println!("{}", LOCAL_CONST);
}
```

**常量** 可以在任意作用域里定义，包括全局作用域。也就是可以在任何地方定义。**常量** 只是一个符号，会在 **编译时** 替换为具体的值。



#### 静态变量



```rust
// 不可变静态变量
static CONFIG_VERSION: &str = "v1.0.0";
static SUPPORTED_LANGUAGES: [&str; 3] = ["zh-CN", "en-US", "ja-JP"];

// 可变静态变量（需要unsafe）
static mut REQUEST_COUNT: u64 = 0;

fn increment_counter() {
    unsafe {
        REQUEST_COUNT += 1;
        println!("请求计数: {}", REQUEST_COUNT);
    }
}

fn main() {
    println!("配置版本: {}", CONFIG_VERSION);
    println!("支持语言: {:?}", SUPPORTED_LANGUAGES);
    increment_counter();
}
```
